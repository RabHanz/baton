# Getting started with Tessaya

Tessaya is a desktop assistant that sits beside your coding agents. You talk or type to it; it looks at your screen when you ask, keeps jobs going in the background, remembers what you teach it, and asks before it does anything that matters.

## Install and first run

1. Install Tessaya for your system. See [Install](./install.md). Windows is the first-class system today; macOS and Linux builds start and run the voice, with fewer features (see [Platforms](../baton/PLATFORMS.md)).
2. Start it. Tessaya lives in the tray and has no window until you ask: click the tray icon, or start it a second time.
3. The first run walks you through the assistant you use, the microphone, wake words, the dictation key, and privacy. It is shown once and can be run again from About.
4. Turn voice on when you want it. Nothing listens until you do, and the speech model (about 740 MB) downloads the first time.

## What to try first

- Hold **Ctrl+Alt+Space**, speak, release: your words are typed into the app you are in. See [Dictation](./tessaya-dictation.md).
- Say a wake word, then ask a question. See [Voice](./tessaya-voice.md).
- Press **Ctrl+Alt+Shift+B** and ask "what's this error?" to have it look at your screen. See [Screen companion](./tessaya-screen.md).
- Give it a job and come back later. See [Jobs and approvals](./tessaya-jobs.md).
- Say "remember that I like short answers". See [Memory](./tessaya-memory.md).
- Keep keys and passwords in the [Vault](./tessaya-vault.md) so no assistant ever sees them.
- Open it on your phone: [Tessaya on your phone](./tessaya-phone.md).

## What it never does without you

It asks before a job starts, before it clicks for you, and before it uses a secret. Anything it read from a web page or a file is treated as information, not as an instruction. You can stop it at any time by saying "stop" or using Clear the screen in the tray.

## Where your data is

Everything stays on your computer: history, memory, the vault (encrypted), settings. The window's About page lists the folders. Nothing is sent anywhere except to the assistant you chose, for the work you asked for.
