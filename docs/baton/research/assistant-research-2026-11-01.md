# Always-on assistants: what Baton takes from them (2026-11-01)

From the record plus one search today. The record: VentureOS ADR-0101 option D ("Good ideas to borrow" from OpenClaw and Hermes, rejected as an outer system), and The Margin session 7307a313, 2026-10-23, on Claude Duet. Most comparison sources are secondary blogs and disagree on prices and details, so check first-party pages before relying on any figure.

| Product                                           | What to take                                                                                                                                                                                                             | Weakness to beat                                                                             |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| Claude Duet (Anthropic, research preview, 21 Oct) | Morning brief, connected-app checks every few hours, one running conversation that reads memory, skills and connectors, its own computer so work continues with devices off, an explicit list of what waits for approval | Reported as over-eager; personal errands such as booking are a weak fit; US waitlist; no API |
| OpenAI dots                                       | Many app connections through plugins; background research that is read-only by default                                                                                                                                   | Memory held on OpenAI's side; clearing it reportedly means deleting the dot                  |
| Meta Muse                                         | Memory as text files he can open and edit; reachable on WhatsApp                                                                                                                                                         | Consumer focus                                                                               |
| Grok Bot                                          | Specialised bots coordinated by a higher-level bot                                                                                                                                                                       | Reported as no way to view or edit memory                                                    |
| OpenClaw                                          | Long-running gateway, many chat channels, cron that reports back to chat                                                                                                                                                 | Reported to forget context                                                                   |
| Hermes Agent                                      | Skills generated from finished work and refined, compact memory plus searchable history, delegation                                                                                                                      | Fewer channels                                                                               |

Baton's position: it runs on his machines with his subscriptions, holds his sessions across accounts and devices, works by voice first, and its memory stays his and editable. None of the above combines those.

Sources: every.to/personal-agents-comparison, aimultiple.com/always-on-agents, explainx.ai/blog/claude-duet-vs-openai-dots-vs-meta-muse-vs-grok-bot-proactive-agents-2026, trevorheshka.com/blog/muse-vs-chatgpt-dots-vs-claude-duet-vs-grok-bot-the-new-always-on-ai-agents-compared/, kingy.ai/blog/claude-duet/, screenshotone.com/blog/hermes-agent-versus-openclaw/, atlantic.net/openclaw-vs-hermes-which-ai-agent-should-you-deploy/.
